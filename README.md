🎵 Soundify – Music Streaming Platform

Soundify is a full-stack music streaming web application inspired by Spotify. It allows users to explore and listen to music while providing artists with a dedicated platform to upload and manage their music.

The project is built using the MERN stack, focusing on modern UI design, secure authentication, RESTful APIs, and efficient music management.


🚀 Features

👤 User Features

- User Registration and Login
- Secure JWT-based Authentication
- Browse and Explore Music
- Search Music
- Stream and Play Songs
- Responsive and Interactive User Interface

🎤 Artist Features

- Dedicated Artist Studio
- Upload Music Tracks
- Manage Uploaded Songs
- Create and Manage Albums
- Organize Music Collections

🔐 Authentication & Security

- JWT-based authentication
- HTTP-only cookie-based session management
- Protected API routes
- Role-based access for Artists and Users
- CORS configuration with credentials support

🛠️ Tech Stack

Frontend

- React.js
- Vite
- JavaScript
- Axios
- CSS / Tailwind CSS

Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- JWT (JSON Web Token)
- Cookie Parser


🔄 Application Workflow

1. Users register or log in to their accounts.
2. Authentication is handled using JWT and secure cookies.
3. Users can browse, search, and play available music.
4. Artists can access their dedicated Artist Studio.
5. Artists can upload music tracks.
6. Uploaded music information is stored in MongoDB.
7. Artists can create albums and organize their uploaded tracks.

🎯 Project Objective

The main objective of Soundify is to develop a real-world full-stack music streaming application while gaining practical experience in:

- Full-stack web development
- REST API development and integration
- Database design and management
- Authentication and authorization
- File uploading and media handling
- Frontend and backend integration
